# Recipes

Pet project / work in progress. Full-stack recipe and cooking platform with a Russian user interface.

v0.1 includes published recipes, servings scaling, nutrition coverage, shopping lists, authenticated administration and local media. See [functional scope](docs/v0.1-functional-scope.md), [admin bootstrap](docs/admin-bootstrap.md), and [media storage](docs/media-storage.md).

Use Node.js 24.20.0 and run `npm ci`. Optional full-stack development is `docker compose -f compose.local.yaml up --build`; see `docs/operations/local-development.md`.
